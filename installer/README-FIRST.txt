CABINET STUDIO 0.3.35 - TESTER README
=====================================

DESIGN AID ONLY - NOT A CERTIFIED UL 508A DRAWING TOOL.
E-stop and safety functions must be hardwired or use rated safety relays
(NFPA 79 / ISO 13849). The software is never the safety function.

HOW TO RUN
- Installer: run CabinetStudio-Setup-0.3.35.exe. It installs for your user
  only (no admin prompt) and adds a Start menu entry (desktop icon optional).
  Uninstall from Settings > Apps.
- Portable ZIP: unzip anywhere (e.g. Documents), open the CabinetStudio
  folder and double-click CabinetStudio.exe. Keep the _internal folder next
  to the exe.
- Needs 64-bit Windows 10 or 11.

USER MANUAL
- Step-by-step manual: Cabinet-Studio-User-Manual.html (open in any web
  browser) or Cabinet-Studio-User-Manual.pdf.
- Inside the app: click "? Manual" on the toolbar, or Help > User manual.
- Installer: Start menu > Cabinet Studio > Cabinet Studio User Manual.

WINDOWS SMARTSCREEN
The program is not code-signed yet, so Windows may show
"Windows protected your PC". Click "More info", then "Run anyway".

WHERE YOUR FILES GO
- Projects, drawings, window layout:  Documents\Cabinet Studio\saves
- AI settings (your API key):          %APPDATA%\CabinetStudio\ai_settings.json
Uninstalling does not delete these.

AI FEATURES
AI help needs your own API key. Enter it in the app's AI Settings. No key
is shipped with this build.

LIVE PLC LINK (BETA)
The live PLC connection is beta. Bench-test it on a test PLC only, never on
running machinery.
